  • Entras a un proyecto en marcha (Staff Augmentation).
  • Cientos de artefactos.

  • Expectativa: Productividad Inmediata.

Arqueología de Código

Mapeando el Territorio

El objetivo no es leer todo el código, sino entender el flujo.

1. El Mapa de Calor Mental

Regla 80/20: Ignora el 80% del código "boilerplate". Concéntrate en el 20% que define el negocio.

  • Identifica los "Caminos Críticos" (Ej: Checkout, Login).
  • Entiende el Qué hace el sistema antes del Cómo lo hace.
  • Usa herramientas de visualización de dependencias.

2. La Huella Digital

Estrategia de Logging

El código puede mentir (comentarios viejos),
los logs dicen la verdad.

  • Ubicación: ¿Splunk, Datadog, AWS CloudWatch? Encuéntralos el Día 1.
  • Estandarización: ¿JSON o Texto plano?
  • Tracing: Busca el Correlation-ID.
[INFO] 2023-10-27 10:00:01
Transaction-ID: a1b2-c3d4-e5f6
Service: Payment-Gateway
Status: Processing...
User: 4521

"Si no puedes seguir la petición, estás ciego."

3. Debugging como Documentación

Haz que el código te cuente su historia ejecutándose.
  • Leer código estático es lento y cognitivamente costoso.
  • Usa Breakpoints para inspeccionar la estructura real de los datos.
  • Analiza el Call Stack para entender quién llama a quién.

Soft Skills en Staff Augmentation

Comunicación Estratégica

  • Gestión de Expectativas: Convierte el "No sé" en "Estoy investigando X para resolver Y".
  • Visibilidad: En remoto, si no comunicas, no estás trabajando.
  • Preguntas Quirúrgicas: Demuestra que ya investigaste (por ejemplo revisaste los logs) antes de preguntar.

Tu Kit de Supervivencia

  • Mapea los flujos críticos (no todo el código).
  • Rastrea los logs (tu fuente de la verdad).
  • Ejecuta el código para entenderlo (Debugging).
  • Comunica progreso constantemente.
